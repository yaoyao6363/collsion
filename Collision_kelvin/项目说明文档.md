# 卫星碰撞风险预测项目 - 完整说明文档

## 项目概述

本项目是一个基于深度学习的卫星碰撞风险预测系统，使用 LSTM 神经网络对卫星碰撞数据（CDM - Conjunction Data Message）进行时序建模，预测碰撞风险值。项目实现了完整的数据预处理、模型训练、验证和测试流程。

## 核心文件详细说明

### 1. `main.py` - 主程序入口

**功能：**
- 解析命令行参数，配置模型、数据和训练参数
- 初始化随机种子，确保实验可复现
- 循环执行多次训练迭代（默认3次）
- 协调训练和测试流程
- 保存训练指标和测试结果

**主要参数：**
- `--model`: 模型类型（当前支持 'LSTM'）
- `--data_path`: 数据集路径
- `--dataset_train/test`: 训练/测试数据文件名
- `--n_latest_cdms`: 每个事件保留的最新CDM数量（默认6）
- `--hidden_size`: LSTM隐藏层大小（默认128）
- `--num_layers`: LSTM层数（默认2）
- `--dropout`: Dropout率（默认0.1）
- `--epoch`: 训练轮数（默认100）
- `--batch_size`: 批次大小（默认128）
- `--lr`: 学习率（默认0.001）
- `--patience`: 早停耐心值（默认5）
- `--seed`: 随机种子（默认43）
- `--device`: GPU设备ID（默认0）

**执行流程：**
1. 解析参数并验证
2. 设置随机种子
3. 对每次迭代（itr次）：
   - 创建 Solver 实例
   - 训练模型（如果非 only_test 模式）
   - 测试模型
   - 保存结果

### 2. `utils/solver.py` - 核心求解器

**功能：**
这是项目的核心模块，包含模型定义、训练和测试逻辑。

#### 2.1 `RegressionSequenceDataset` 类
- **功能：** PyTorch Dataset 封装，将 NumPy 数组转换为 PyTorch 张量
- **输入：** 特征数组和目标值数组
- **输出：** 返回 `(data, target)` 元组

#### 2.2 `RiskLSTM` 类
- **功能：** LSTM 回归模型
- **结构：**
  - 多层 LSTM（可配置层数和隐藏单元数）
  - Dropout 层（防止过拟合）
  - 全连接输出层（输出单个风险值）
- **前向传播：** 使用 LSTM 的最后一个时间步输出进行预测

#### 2.3 `compute_metrics` 函数
- **功能：** 计算回归评估指标
- **指标：**
  - MSE（均方误差）
  - MAE（平均绝对误差）
  - RMSE（均方根误差）
  - MAPE（平均绝对百分比误差）
  - R²（决定系数）

#### 2.4 `Solver` 类
**主要方法：**

- `__init__`: 初始化求解器
  - 获取设备（GPU/CPU）
  - 创建模型保存目录
  - 加载数据并创建 DataLoader
  - 初始化模型、优化器、学习率调度器、早停机制

- `_acquire_device`: 获取计算设备
  - 根据 `use_gpu` 参数选择 GPU 或 CPU

- `_make_dirs`: 创建模型保存目录

- `_get_loader`: 创建数据加载器
  - 读取并预处理训练数据
  - 使用 `CreateDataset` 生成回归数据集
  - 标准化特征数据
  - 按比例分割训练/验证/测试集
  - 创建 PyTorch DataLoader

- `_save_metrics_to_csv`: 保存训练指标到 CSV 文件

- `train`: 训练模型
  - 训练循环：前向传播、计算损失、反向传播
  - 验证循环：评估模型性能
  - 计算并打印评估指标
  - 使用早停机制保存最佳模型
  - 返回训练轮数和指标列表

- `test`: 测试模型
  - 加载最佳模型权重
  - 在测试集上评估
  - 计算并打印测试指标
  - 保存测试结果到文件

### 3. `utils/dataset.py` - 数据集创建

**功能：** 处理原始数据，生成用于训练和测试的序列数据集。

#### 3.1 `CreateDataset` 类

**主要方法：**

- `__init__`: 初始化
  - 设置是否只使用最新 CDM
  - 设置每个事件保留的 CDM 数量（`n_latest_cdms`）

- `split_input_output_seq`: 分割输入输出序列
  - 对每个事件，保留最新的 N 个 CDM
  - 过滤掉只有一个 CDM 的事件
  - 提取每个事件的最后一行作为输出（真实风险值）
  - 删除 TCA（最接近时间）最小的行
  - 返回输入序列列表和输出序列列表

- `drop_least_tca`: 删除每个事件中 TCA 最小的行
  - 用于确保输入序列不包含最终的真实值

- `last_row_by_event_id`: 获取每个事件的最后一行
  - 用于提取真实的风险值作为标签

- `custom_train_test_split`: 自定义训练/验证/测试分割
  - 按 `risk_category` 分组，保持各类别比例
  - 先分割训练集和测试集（默认 70% / 30%）
  - 再从测试集中分割验证集和测试集（默认各 50%）
  - 返回三个 DataFrame

- `get_train_test_dataset`: 获取训练和测试数据集
  - 调用 `custom_train_test_split` 分割数据
  - 合并验证集和测试集
  - 分别处理分类和回归任务的数据
  - 使用 `DataUtils.pad_matrix` 填充序列到固定长度
  - 返回分类数据集和回归数据集的元组

### 4. `utils/data_preprocessor.py` - 数据预处理

**功能：** 对原始 CSV 数据进行清洗和特征工程。

**主要函数：**

- `split_risk_range`: 风险分级
  - 根据风险值创建 `risk_range` 列
  - 风险 > -6: 0（高风险）
  - -20 ≤ 风险 ≤ -6: 1（中风险）
  - 风险 ≤ -20 或 = -30: 1（低风险）

- `remove_shorter_events`: 删除短事件
  - 过滤掉 TCA 前 2 天没有数据的事件
  - 确保每个事件在 TCA 前后都有观测数据

- `assign_risk_category`: 分配风险类别
  - 为每个事件分配风险类别（基于 TCA 前 2 天的风险值）
  - 过滤数据，只保留 TCA 前 2 天之后的数据

- `assign_risk_change_rate`: 分配风险变化率
  - 计算每个事件内风险值随时间的变化率
  - 用于捕获风险趋势

- `handle_missing_values`: 处理缺失值
  - 对特定列（`c_time_lastob_end`, `c_time_lastob_start`）填充 -1
  - 删除其他包含缺失值的列
  - 保存处理后的数据为 Feather 格式

- `pre_data`: 主预处理函数
  - 读取 CSV 文件
  - 对 `c_object_type` 进行标签编码
  - 依次执行上述所有预处理步骤
  - 返回处理后的 DataFrame

- `split_risk_range`: 风险范围分割（与 data_preprocessor 中的类似）

- `drop_least_tca`: 删除最小 TCA 行

- `pad_matrix`: 矩阵填充

- `split_array`: 数组分割

### 8. `utils/stoper.py` - 早停机制

**功能：** 实现早停（Early Stopping）机制，防止过拟合。

**类：`Stopper`**

**属性：**
- `patience`: 耐心值（验证损失不改善的最大轮数）
- `counter`: 当前计数器
- `best_score`: 最佳分数
- `early_stop`: 是否早停标志
- `val_loss_min`: 最小验证损失
- `path`: 模型保存路径

**方法：**
- `__call__`: 调用时检查验证损失
  - 如果损失改善，保存模型并重置计数器
  - 如果损失未改善，增加计数器
  - 当计数器达到耐心值时，触发早停

- `save_checkpoint`: 保存模型检查点

## 数据流程

### 1. 数据预处理流程

```
原始 CSV 数据 (dataset/train_data.csv)
    ↓
读取数据 (pre_data)
    - 原始数据：约 162,634 行，13,154 个事件
    ↓
标签编码 (c_object_type)
    ↓
风险分级 (split_risk_range)
    ↓
删除短事件 (remove_shorter_events)
    - 过滤后：约 96,746 行，8,892 个事件（过滤掉约 32% 的事件）
    ↓
分配风险类别 (assign_risk_category)
    ↓
计算风险变化率 (assign_risk_change_rate)
    ↓
处理缺失值 (handle_missing_values)
    ↓
保存为 Feather 格式
```

### 1.1 数据量变化说明

**重要提示：** 项目确实使用 `dataset/` 文件夹中的数据，但经过处理后数据量会显著减少：

1. **原始数据**：`dataset/train_data.csv` 包含约 162,634 行，13,154 个事件
2. **预处理后**：约 96,746 行，8,892 个事件（过滤掉不符合条件的事件）
3. **最终训练样本**：约 5,887 个样本（每个事件变成一个训练样本）
4. **最终测试样本**：约 2,526 个样本

**数据量减少的原因：**
- `remove_shorter_events`: 删除 TCA 前 2 天没有数据的事件（约 32% 的事件被过滤）
- `split_input_output_seq`: 每个事件只保留最新的 N 个 CDM（默认 6 个），然后转换为一个样本
- `drop_least_tca`: 删除每个事件中 TCA 最小的行（用于避免数据泄露）

**训练速度快的原因：**
- 训练样本数量相对较少（约 6K 样本）
- 序列长度短（`n_latest_cdms=6`，实际序列长度为 5）
- 特征维度小（12 个回归特征）
- 模型规模小（LSTM hidden_size=128, num_layers=2，参数量约 20 万）
- 使用 GPU 加速
- 批次大小适中（batch_size=128，每个 epoch 约 46 个批次）

### 2. 训练流程

```
预处理后的数据 (约 8,892 个事件)
    ↓
CreateDataset.get_train_test_dataset()
    ↓
按事件分组，提取最新 N 个 CDM (n_latest_cdms=6)
    - 每个事件保留最新的 6 个 CDM
    - 过滤掉只有 1 个 CDM 的事件
    ↓
分割输入输出序列
    - 输入：每个事件的前 5 个 CDM (n_latest_cdms - 1)
    - 输出：每个事件的最后一个 CDM 的风险值
    ↓
自定义训练/验证/测试分割 (70% / 15% / 15%)
    - 训练集：约 5,887 个样本
    - 验证集：约 1,261 个样本（从训练集中再分割）
    - 测试集：约 2,526 个样本
    ↓
特征提取和填充
    - 提取 12 个回归特征
    - 填充序列到固定长度 (5 个时间步)
    - 最终形状：(样本数, 5, 12)
    ↓
标准化
    - 使用训练集的均值和标准差标准化所有数据
    ↓
创建 DataLoader
    - 训练集：batch_size=128，约 46 个批次/epoch
    - 验证集：batch_size=128，约 10 个批次/epoch
    - 测试集：batch_size=128，约 20 个批次/epoch
    ↓
训练循环（每个 epoch）
    ├─ 前向传播 (46 个批次)
    ├─ 计算损失 (MSE)
    ├─ 反向传播
    └─ 更新参数
    ↓
验证循环（每个 epoch）
    ├─ 评估性能 (10 个批次)
    ├─ 计算指标 (MSE, MAE, RMSE, MAPE, R²)
    └─ 早停检查
    ↓
保存最佳模型
```

**训练速度估算：**
- 每个 epoch 约 46 个训练批次 + 10 个验证批次 = 56 个批次
- 在 GPU 上，每个批次约 0.01-0.02 秒
- 每个 epoch 约 0.5-1 秒
- 100 个 epoch 约 50-100 秒（不含早停）

### 3. 测试流程

```
加载最佳模型权重
    ↓
在测试集上评估
    ↓
计算测试指标
    ↓
保存结果到文件
```

## 模型架构

### LSTM 模型结构

```
输入序列 (batch_size, seq_len, feature_dim)
    ↓
LSTM 层 (多层，可配置)
    ├─ hidden_size: 128 (默认)
    ├─ num_layers: 2 (默认)
    └─ dropout: 0.1 (默认)
    ↓
取最后一个时间步的输出
    ↓
Dropout
    ↓
全连接层 (hidden_size → 1)
    ↓
输出：风险值预测
```

## 评估指标

项目使用以下指标评估模型性能：

1. **MSE (Mean Squared Error)**: 均方误差
2. **MAE (Mean Absolute Error)**: 平均绝对误差
3. **RMSE (Root Mean Squared Error)**: 均方根误差
4. **MAPE (Mean Absolute Percentage Error)**: 平均绝对百分比误差
5. **R² (R-squared)**: 决定系数，衡量模型解释方差的比例

## 注意事项

1. **NumPy 版本**: 建议使用 NumPy < 2.0，因为某些依赖库可能不兼容 NumPy 2.x
2. **数据路径**: 确保 `dataset/` 目录下存在 `train_data.csv` 和 `test_data.csv`
3. **GPU 内存**: 如果 GPU 内存不足，可以减小 `batch_size` 或 `hidden_size`
4. **随机种子**: 使用相同的随机种子可以复现实验结果

## 项目特点

1. **时序建模**: 使用 LSTM 捕获卫星碰撞风险的时序特征
2. **事件级处理**: 按事件（event_id）组织数据，每个事件包含多个时间点的 CDM
3. **特征工程**: 包含风险分级、风险变化率等工程特征
4. **完整流程**: 从数据预处理到模型训练、验证、测试的完整流程
5. **可扩展性**: 模型架构和数据处理模块化，易于扩展
