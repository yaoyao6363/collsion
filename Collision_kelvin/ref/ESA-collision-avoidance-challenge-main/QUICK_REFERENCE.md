# 快速参考 - 评估指标

## 🎯 所有指标一览

| 指标 | 全称 | 范围 | 越小越好? | 说明 |
|------|------|------|-----------|------|
| **MSE** | Mean Squared Error | [0, ∞) | ✅ | 均方误差，对大误差敏感 |
| **RMSE** | Root Mean Squared Error | [0, ∞) | ✅ | 均方根误差，与原数据同量纲 |
| **MAE** | Mean Absolute Error | [0, ∞) | ✅ | 平均绝对误差，对异常值不敏感 |
| **MAPE** | Mean Absolute Percentage Error | [0, ∞) | ✅ | 平均绝对百分比误差，相对误差 |
| **R²** | Coefficient of Determination | (-∞, 1] | ❌ | 决定系数，1表示完美拟合 |
| **F2** | F-beta Score (beta=2) | [0, 1] | ❌ | F2分数，更重视召回率 |

## 🔍 指标解读

### MSE = 25.64
```
含义: 预测误差平方的平均值
解读: 平均误差较大，存在一些预测偏差较大的样本
建议: 检查异常样本，考虑特征工程
```

### RMSE = 5.06
```
含义: MSE的平方根，与风险值同量纲（对数尺度）
解读: 平均预测偏差约5个对数单位
建议: 对于对数尺度的风险值，这是可接受的范围
```

### MAE = 2.67
```
含义: 绝对误差的平均值
解读: 比RMSE小很多，说明大部分预测较准确，但有少数大误差
建议: 识别并处理异常预测样本
```

### MAPE = 18.43%
```
含义: 相对误差的百分比
解读: 平均相对误差约18%，接近20%的警戒线
建议: 对于风险预测，这是可接受的，但有改进空间
```

### R² = 0.72
```
含义: 模型解释的方差比例
解读: 模型解释了72%的数据变化，拟合效果良好
建议: 已达到良好水平，可尝试更复杂模型提升至0.8+
```

### F2 = 0.52
```
含义: 基于阈值-6的分类F2分数（beta=2，重视召回率）
解读: 高风险检测能力一般，主要受类别不平衡影响
建议: 使用过采样、调整阈值或代价敏感学习
```

## 🎓 公式速查

### MSE
```
MSE = (1/n) * Σ(y_true - y_pred)²
```

### RMSE
```
RMSE = √MSE
```

### MAE
```
MAE = (1/n) * Σ|y_true - y_pred|
```

### MAPE
```
MAPE = (100/n) * Σ|y_true - y_pred| / |y_true|
```

### R²
```
R² = 1 - (SS_res / SS_tot)
SS_res = Σ(y_true - y_pred)²
SS_tot = Σ(y_true - ȳ)²
```

### F2-score
```
F2 = 5 * (Precision * Recall) / (4 * Precision + Recall)

Precision = TP / (TP + FP)
Recall = TP / (TP + FN)

其中:
TP = True Positives  (预测高风险 & 真实高风险)
FP = False Positives (预测高风险 & 真实低风险)
FN = False Negatives (预测低风险 & 真实高风险)
```

## 📞 问题排查

### Q: 为什么F2-score这么低？
A: 主要原因是类别严重不平衡（49 vs 1213），可以尝试：
   - SMOTE过采样
   - 调整分类阈值
   - 使用代价敏感学习

### Q: MAPE和MAE的区别？
A: 
   - MAE: 绝对误差，单位与原数据相同
   - MAPE: 相对误差百分比，无量纲，便于跨数据集比较

### Q: R²可以为负吗？
A: 可以！R²<0 表示模型比简单的均值预测还差

### Q: 如何选择最佳模型？
A: 综合考虑：
   1. Recall > 0.75 (确保高风险检出)
   2. F2 > 0.60 (平衡精确率和召回率)
   3. R² > 0.70 (整体拟合良好)
